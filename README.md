# LEMINI Microservices Platform

**Engineered with Java 17, Spring Boot 3, and Spring Cloud.**

## Project Vision
**LEMINI** is a cloud-native microservices ecosystem designed for the AI era. It combines a rock-solid backend foundation—featuring secure user authentication and smart traffic routing—with a built-in Generative AI Orchestrator. The result is a platform that seamlessly blends secure, scalable infrastructure with intelligent, automated data processing.


## Core Tech Stack
- **Languages:** Java 17
- **Frameworks:** Spring Boot 3.x, Spring Cloud 2023.x, Spring Security 6
* **AI & Data:** Spring AI, Ollama (Local LLM Inference), ChromaDB (Vector Store)
- **Database:** MySQL (Primary), H2 (Dev/Test), ChromaDB (Vector Store for AI)
- **Infrastructure:** Maven (Monorepo), Docker, Kubernetes (Minikube)
- **Observability:** Micrometer, Zipkin
