# LEMINI Microservices Platform

## Project Vision
**LEMINI** is a cloud-native microservices platform engineered with Java 17, Spring Boot 3, and Docker. It features a robust, secure infrastructure including centralized configuration, dynamic service discovery, and a unified API Gateway. The platform integrates a secure User Identity service with JWT authentication alongside a centralized Generative AI Orchestrator, delivering a seamless blend of scalable backend architecture and intelligent automation.

## Core Tech Stack
- **Languages:** Java 17
- **Frameworks:** Spring Boot 3.x, Spring Cloud 2023.x, Spring Security 6
- **Database:** MySQL (Primary), H2 (Dev/Test), ChromaDB (Vector Store for AI)
- **Infrastructure:** Maven (Monorepo), Docker, Kubernetes (Minikube)
- **Observability:** Micrometer, Zipkin
